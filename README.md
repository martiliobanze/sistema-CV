# Sistema de Geração de Currículos Personalizados

Este projecto consiste numa aplicação web prática desenvolvida em **Python (Flask)** que permite a qualquer utilizador introduzir os seus dados profissionais e obter um Currículo formatado em PDF de forma instantânea.

## Características do Projecto

* **Automação Comercial:** O descarregamento do documento está condicionado à confirmação de um pagamento electrónico prévio.
* **Soluções de Pagamento:** Integração conceptual com as redes móveis mais utilizadas em Moçambique (**M-Pesa** e **e-Mola**).
* **Geração de Ficheiros:** Utilização da biblioteca *ReportLab* para conceber o PDF directamente na memória do servidor, optimizando o espaço em alojamentos gratuitos.
* **Alojamento Directo:** Estrutura concebida para ser colocada em produção de modo totalmente gratuito através de plataformas como o *Render* ou *Railway*, sem necessidade de manter um computador doméstico ligado.

## Objectivo

Permitir que o administrador da plataforma obtenha proveito financeiro de forma directa e automatizada através de transacções móveis, facultando uma óptima experiência de utilização ao cliente final.
